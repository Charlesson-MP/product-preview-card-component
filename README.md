# 🛍️ Product Preview Card Component

## 📖 About the Project

This project is a responsive product preview card component developed as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge. It features a product presentation layout with an image, product category, name, description, pricing information, and an "Add to Cart" button.

The main goal was to practice HTML5 and CSS3 concepts while recreating a clean and responsive design that adapts to different screen sizes.

## ✨ Features

- Responsive layout for desktop and mobile devices.
- Adaptive product images for different screen sizes.
- Clean and modern product presentation.
- Custom typography using Google Fonts.
- CSS custom properties for consistent styling.
- Interactive button hover and focus states.

## 🚀 Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/Charlesson-MP/product-preview-card-component.git
```

2. Navigate to the project directory:

```bash
cd product-preview-card-component
```

3. Open the `index.html` file in your browser.

No additional dependencies or installation steps are required.
